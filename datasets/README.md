# Datasets

No dataset is bundled with this repository. Data is fetched only on a decision recorded in
the plan, and never committed.

## Rules

1. **Licence first.** An asset may only enter `datasets/raw/` after its licence and
   source have been recorded in a `Provenance` block. `datasets/schema.py` refuses
   to construct a `Provenance` without both.
2. **No scraping.** Anatomical atlases, scan archives and model libraries are not
   collected opportunistically. Each source is reviewed for terms of use first,
   and the review is recorded in the sample metadata.
3. **Anatomy is anchored to the ontology.** A sample's parts are ontology entity
   ids, never free text, so a mesh part and `heart.left_ventricle` can be checked
   against each other.
4. **Binary assets are never committed.** `.gitignore` excludes `datasets/raw/`
   and `datasets/processed/` along with common mesh and volume formats.

## Layout

| Path                    | Contents                                                     |
| ----------------------- | ------------------------------------------------------------ |
| `datasets/raw/`         | Licensed source assets, git-ignored. Each source is listed with its licence record in `tests/test_datasets.py`. |
| `datasets/processed/`   | Generated corpora (text), and derived Level 1/2 assets in `level1/` and `level2a/` (meshes, models), git-ignored. |
| `datasets/annotations/` | Sample metadata as JSON. Committed. Currently one synthetic example. |

## Current state

`datasets/annotations/heart_sample_0001.json` is **synthetic metadata**. It has no
image, no mesh and no measurement behind it. It exists so the schema has a worked
example and so validation has something to run against.

**Real data, since Level 1.** With the user's approval (2026-10-15 and 2026-10-16), 200
subjects' label masks were fetched from the **TotalSegmentator dataset v1.0** (Wasserthal et
al., Zenodo 10.5281/zenodo.6802614, **CC BY 4.0**) into `datasets/raw/totalsegmentator_v1/`:
278 MB, by HTTP byte range, from a 28.4 GB archive.
- The licence, source and attribution are recorded in
  `assets/labels/totalsegmentator_v1.json` and in `fetch_report.json`.
- They travel into every derived scene's manifest and the shape models' `provenance.json`
  (ADR-L1-004).

`datasets/raw/phantom/` is generated by `assets.phantom` and needs no licence.
