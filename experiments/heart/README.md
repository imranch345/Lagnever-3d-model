# Heart experiments

Specifications only. Nothing in this folder trains a model, and no result exists.

| File | Contents |
| --- | --- |
| `experiment_001_structured_vs_appearance.py` | Pre-registered plan for the first ablation: structured anatomical representation versus an appearance-driven baseline. |

```bash
python -m experiments.heart.experiment_001_structured_vs_appearance
```

The success criteria are written down before any model is built, so a threshold
cannot be adjusted to fit a result. The plan has no results field, on purpose.

## Data

The first run uses a **tier-0 synthetic corpus** generated by this project: one
primitive per ontology entity, varied within ordered ranges, with exact part
labels and relationships. It carries no licensing exposure and is explicitly not
anatomically realistic. It measures whether the representation gives better
semantic control, which is the research question. It says nothing about clinical
accuracy, and no result from it may be presented as if it did.

Real segmented cardiac data is tier-1 and is not acquired. Every candidate source
must pass the licence review recorded in `datasets/README.md` first.
